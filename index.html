MarkRead

一个为「舒适阅读」而生的 macOS Markdown 阅读器。

  • 打开：菜单 文件 › 打开，或拖入文件，或拖到程序图标
  • 三种模式：阅读 / 双栏（左编辑右预览）/ 编辑，工具栏切换或 Cmd+E
  • 修改：在「双栏」或「编辑」模式下直接改文本，Cmd+S 保存到文件（Cmd+Shift+S 另存为）
  • 自动保存：编辑/双栏模式下，有文件路径时输入后约 1 秒自动写回原文件（脏点消失即表示已存）
  • 自定义栏宽：双栏模式下按住中间分隔条左右拖动，可调整左编辑器与右预览的宽度（自动记忆）
  • 点击关联：双栏模式下，双击左侧编辑区 → 右侧预览跳到对应段落；双击右侧正文 → 左侧编辑器光标定位到对应源行。也可用工具栏「↦ 预览 / ↤ 编辑」按钮，或 Cmd+Enter 双向跳转
  • 主题：浅色 / 护眼 / 深色，快捷键 Cmd+T
  • 字号：Cmd+ +/-/0
  • 目录：Cmd+\ 切换侧边大纲
  • 多文档（标签页）：右键 md 选「打开方式 → MarkRead」、拖入文件、或菜单「打开」，都会新开一个标签页；点标签切换，标签上的 × 关闭。已打开的文件再次打开会直接切到对应标签
